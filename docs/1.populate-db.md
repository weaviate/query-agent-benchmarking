# 1. Populate Database

The `database_loader()` function downloads a dataset and populates a Weaviate collection.

## Configuration

Edit `database/database_loader_config.yml` to set the dataset and embedding model:

```yaml
dataset_name: bright/biology

embedding_model: "weaviate/Snowflake/snowflake-arctic-embed-l-v2.0"
```

## Usage

```python
import query_agent_benchmarking

query_agent_benchmarking.database_loader()
```

Or from the command line:

```bash
uv run python scripts/populate-db.py
```

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `recreate` | `bool` | `True` | Whether to drop existing collection before creating |
| `tag` | `str` | `"Default"` | Suffix added to collection name |

## Collection Naming

Collections are named `{DatasetPrefix}{PascalizedSubset}_{Tag}`. For example, `bright/biology` with the default tag becomes `BrightBiology_Default`.

An alias (e.g., `BrightBiology`) is also created or updated to point to the tagged collection.

**QueryAgentGym** is the exception: each environment creates several collections, named after the dataset's own schema (e.g. `query-agent-gym/surf-schools` creates `SurfBeaches_Default`, `SurfInstructors_Default`, `LessonPrograms_Default` and `SurfEquipment_Default`, each with an alias).

## Supported Datasets

**BEIR**: `beir/fiqa/test`, `beir/nq`, `beir/scifact/test`

**BRIGHT**: `bright/biology`, `bright/earth_science`, `bright/economics`, `bright/psychology`, `bright/robotics`

**Enron**: `enron`

**FreshStack**: `freshstack-angular`, `freshstack-godot`, `freshstack-langchain`, `freshstack-laravel`, `freshstack-yolo`

**IRPapers**: `irpapers/images`, `irpapers/text`

**LoTTe**: `lotte/lifestyle/test/forum`, `lotte/lifestyle/test/search`, `lotte/recreation/test/forum`, `lotte/recreation/test/search`

**WixQA**: `wixqa`

**MultiHop-RAG**: `multihoprag`

**OBLIQ-Bench**: `obliq-bench-congress`

**QueryAgentGym**: `query-agent-gym/public-transit`, `query-agent-gym/tattoo-studios`, `query-agent-gym/nonprofits`, `query-agent-gym/surf-schools`, `query-agent-gym/childcare`

Unlike the other datasets, QueryAgentGym's schemas are part of the dataset: each environment's `schema.json` is read at load time instead of being declared in `database_registry.py`. Collection and property descriptions are carried over so the Query Agent sees them. Only `searchable_text` properties are vectorized (collections without any get no vectorizer). Identifier, reference and category text uses `field` tokenization, so `=` and `LIKE` match whole values. Dates are stored as RFC 3339, and every object keeps its dataset `uuid`.

## Embedding Models

| Model | Provider |
|-------|----------|
| `weaviate/Snowflake/snowflake-arctic-embed-l-v2.0` | Weaviate |
| `weaviate/Snowflake/snowflake-arctic-embed-m-v1.5` | Weaviate |
| `cohere/embed-v4.0` | Cohere (requires `COHERE_API_KEY`) |
| `voyageai/voyage-3-large` | Voyage AI (requires `VOYAGEAI_API_KEY`) |

## Environment Variables

Requires `WEAVIATE_URL` and `WEAVIATE_API_KEY`. Third-party embedding providers may also need `COHERE_API_KEY` or `VOYAGEAI_API_KEY`.
