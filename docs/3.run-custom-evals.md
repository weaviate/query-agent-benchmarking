# 3. Run Custom Evals

## Custom Search Eval

Use `DocsCollection` and `QueriesCollection` to evaluate against your own Weaviate collections.

```python
import query_agent_benchmarking
from query_agent_benchmarking import DocsCollection, QueriesCollection

docs_collection = DocsCollection(
    collection_name="BrightBiology", # name of the collection to search through
    content_key="content", # searchable property name
    id_key="dataset_id", # dataset id property
)

queries_collection = QueriesCollection(
    collection_name="SyntheticBrightBiology", # name of collection containing queries
    query_content_key="simulated_user_query", # property name containing the query
    gold_ids_key="dataset_ids", # property name containing the document ids the query should return
)

query_agent_benchmarking.run_search_eval(
    docs_collection=docs_collection,
    queries=queries_collection,
)
```

You can also pass queries directly as a list of `InMemoryQuery` objects:

```python
from query_agent_benchmarking import run_search_eval, DocsCollection, InMemoryQuery

docs_collection = DocsCollection(
    collection_name="MyCollection",
    content_key="content",
    id_key="doc_id",
)

queries = [
    InMemoryQuery(question="What is vector search?", dataset_ids=["doc_1", "doc_5"]),
    InMemoryQuery(question="How does HNSW work?", dataset_ids=["doc_3"]),
]

run_search_eval(
    docs_collection=docs_collection,
    queries=queries,
)
```

## Custom Ask Eval

Use `DocsCollection` and `AskQueriesCollection` to evaluate question answering against your own collections.

```python
import query_agent_benchmarking
from query_agent_benchmarking import DocsCollection, AskQueriesCollection

docs_collection = DocsCollection(
    collection_name="MyDocs",
    content_key="content",
    id_key="doc_id",
)

ask_queries = AskQueriesCollection(
    collection_name="MyQuestions",
    query_content_key="question", # property containing the question
    answer_key="ground_truth", # property containing the expected answer
    oracle_context_id_key="context_id", # optional: property with the gold document id
)

query_agent_benchmarking.run_ask_eval(
    docs_collection=docs_collection,
    queries=ask_queries,
)
```

Or pass queries directly as a list of `InMemoryAskQuery` objects:

```python
from query_agent_benchmarking import run_ask_eval, DocsCollection, InMemoryAskQuery

docs_collection = DocsCollection(
    collection_name="MyDocs",
    content_key="content",
    id_key="doc_id",
)

queries = [
    InMemoryAskQuery(
        question="What is HyDE?",
        ground_truth_answer="HyDE stands for Hypothetical Document Embeddings...",
    ),
]

run_ask_eval(
    docs_collection=docs_collection,
    queries=queries,
)
```

## Bring Your Own Retriever

Pass any retriever directly to `run_search_eval()` via the `search_agent` parameter. Your object must implement the `SearchAgent` protocol — the key method is `run()`, which takes a query string and returns a ranked `list[ObjectID]`.

### The SearchAgent Protocol

```python
from query_agent_benchmarking import SearchAgent, ObjectID

class SearchAgent(Protocol):
    def run(self, query: str, tenant: str | None = None) -> list[ObjectID]: ...
    async def run_async(self, query: str, tenant: str | None = None) -> list[ObjectID]: ...
    async def initialize_async(self) -> None: ...
    async def close_async(self) -> None: ...
```

`SearchAgent` is a `runtime_checkable` Protocol — you don't need to subclass it, just implement the methods. The library validates your object at runtime and raises `TypeError` with a clear message if the interface isn't satisfied.

### Minimal example

```python
from query_agent_benchmarking import run_search_eval, ObjectID

class MyRetriever:
    def run(self, query, tenant=None):
        results = my_search_function(query)
        return [ObjectID(object_id=doc_id) for doc_id in results]

    async def run_async(self, query, tenant=None):
        return self.run(query, tenant)

    async def initialize_async(self): pass
    async def close_async(self): pass

metrics = run_search_eval(
    search_dataset="beir/scifact/test",
    search_agent=MyRetriever(),
)
```

### With custom queries and documents

When your documents live in a Weaviate collection but you want to evaluate your own retrieval logic:

```python
from query_agent_benchmarking import run_search_eval, DocsCollection, InMemoryQuery

metrics = run_search_eval(
    docs_collection=DocsCollection(
        collection_name="MyDocs",
        content_key="content",
        id_key="doc_id",
    ),
    queries=[
        InMemoryQuery(question="What is vector search?", dataset_ids=["doc_1", "doc_5"]),
        InMemoryQuery(question="How does HNSW work?", dataset_ids=["doc_3"]),
    ],
    search_agent=MyRetriever(),
)
```

### Using as a dependency in another library

When integrating `query-agent-benchmarking` as a dependency, you can import the `SearchAgent` protocol for type checking without coupling to any concrete implementation:

```python
# my_library/evaluate.py
from query_agent_benchmarking import run_search_eval, SearchAgent, ObjectID

def benchmark_retriever(retriever: SearchAgent, dataset: str = "beir/scifact/test"):
    """Evaluate any SearchAgent-compatible retriever on a standard benchmark."""
    return run_search_eval(
        search_dataset=dataset,
        search_agent=retriever,
        use_async=True,
    )
```

Any object that satisfies the protocol works — no inheritance required:

```python
# my_library/retriever.py
from query_agent_benchmarking import ObjectID

class ChromaRetriever:
    def __init__(self, collection):
        self.collection = collection

    def run(self, query, tenant=None):
        results = self.collection.query(query_texts=[query], n_results=20)
        return [ObjectID(object_id=id_) for id_ in results["ids"][0]]

    async def run_async(self, query, tenant=None):
        return self.run(query, tenant)

    async def initialize_async(self): pass
    async def close_async(self): pass
```

### Notes

- When `search_agent` is provided, the `agent_name` parameter is ignored and no factory lookup occurs.
- The `agent_name` in saved results defaults to your class name (e.g., `"ChromaRetriever"`). Override it by also passing `agent_name="my-custom-name"`.
- Both sync (`use_async=False`) and async (`use_async=True`) execution paths work with user-provided agents.
- Multi-trial runs reuse the same agent instance across trials.

## BYOS (Bring Your Own System)

If your retriever runs as a separate HTTP service rather than in-process, use BYOS mode instead of `search_agent`:

Both `run_search_eval()` and `run_ask_eval()` support evaluating an external service via `agent_name="external_service"` and `external_service_host`.

**Search**: Your service should accept `POST {"query": "..."}` and return `{"results": ["id1", "id2", ...]}`.

**Ask**: Your service should accept `POST {"question": "...", "oracle_context_id": "..."}` and return `{"answer": "..."}`.

```python
query_agent_benchmarking.run_search_eval(
    search_dataset="beir/scifact/test",
    agent_name="external_service",
    external_service_host="http://localhost:8000/search",
)
```
